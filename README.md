# Курс по Java от компании SENLA

Репозиторий с домашними заданиями по курсу Java от компании SENLA.  
В каждой ветке представлена домашняя работа по номеру лекции в формате: `Task-[№ лекции]`.

## 📁 Структура проекта

```
java-course/
├── README.md
└── task-2/              # Домашнее задание к лекции 2
    ├── 1/               # Задание 1: Hello World на Java
    ├── 2/               # Задание 2: (в разработке)
    ├── 3/               # Задание 3: Скриншоты (клиент, резюме)
    └── 4/               # Задание 4: Скриншот игры "Сапёр"
```

## 🚀 Как начать работу

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка на репозиторий>
   ```

2. **Переключитесь на нужную ветку:**
   ```bash
   git checkout Task-[№ лекции]
   ```

3. **Для работы с Java-файлами:**
   ```bash
   # Компиляция
   javac имя_файла.java
   
   # Запуск
   java имя_класса
   ```
